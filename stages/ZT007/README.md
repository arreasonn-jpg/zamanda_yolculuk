# ZT-007 — Full-Wave Maxwell (planned, not started)

Reserved for the transition from the controlled magnetoquasistatic model
(ZT-005) to a full-wave Maxwell treatment. Motivation: resonance scans
raise the drive frequency, growing L/lambda beyond the quasistatic regime
(at 1 MHz with L ~ 2.5 m, lambda ~ 300 m, so MQS is still defensible).

No code exists for this stage yet.
